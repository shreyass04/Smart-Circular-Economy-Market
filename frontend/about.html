About SCEM

Smart Circular Economy Market is a full-stack platform that helps people record their waste, discover smart ways to reuse it, and track their environmental impact.

What It Does

📝

Manage Waste

Add, view, search and filter waste items by type, quantity and location.

🤖

AI Suggestions

Get reuse and recycling ideas from Gemini AI, with a rule-based backup when the AI is busy.

📊

Track Impact

A dashboard shows total items, weight and estimated CO₂ saved.

Tech Stack

HTML / CSS / JavaScript Java Spring Boot REST API MySQL Google Gemini
